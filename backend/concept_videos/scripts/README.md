# Concept Video Scripts

This folder holds narration scripts and scene beat sheets for Manim concept
videos.

Use one Markdown file per video. Keep the script close to the animation plan:

- `Goal`: what the learner should understand by the end.
- `Scene Beats`: the ordered visual/narration plan.
- `Narration Draft`: voiceover text that can be read aloud.
- `Manim Notes`: reusable objects, transitions, timing, and render concerns.

The Manim implementation lives in `backend/concept_videos/scenes/`.
